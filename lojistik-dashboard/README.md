# Lojistik Teslimat Performans Dashboard

Lojistik Teslimat Raporu + İrsaliye Detay Raporu → siparişten teslimata süreç analizi.

## Yerel çalıştırma
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dosyalar
- `data_pipeline.py` — okuma, irsaliye no normalizasyonu, birleştirme, metrikler, Excel çıktısı
- `app.py` — Streamlit arayüzü
